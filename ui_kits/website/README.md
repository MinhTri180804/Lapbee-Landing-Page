# LAPBEE website UI kit
Click-through recreation of the marketing site. Open `index.html`.

Screens: Trang chủ (Home.jsx), Đội ngũ + Hành trình (About.jsx), Bài đăng list + article (Posts.jsx), Đặt lịch form (Booking.jsx). Shared Header/Footer/SectionHead/Placeholder/PageHero in Shell.jsx; layout + breakpoints (1024 / 820 / 560) in site.css; sample copy in data.js.

All names, milestones (except 2012 LAPPY founding), phone, address and posts are **sample content** — replace with real data. No source website existed; this layout is an original design built on the LAPBEE tokens.

Motion lives in `motion.js` (Lenis smooth scroll, scroll reveals via IntersectionObserver, header hide/progress, hero parallax) plus the top of `site.css`.
