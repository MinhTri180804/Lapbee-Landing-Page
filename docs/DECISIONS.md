## Bảo mật dependency

- `npm audit` (18.11.2026): **0 lỗ hổng ở dependency runtime** (`npm audit --omit=dev`).
- Có 14 cảnh báo mức high ở dev dependency, tất cả đến từ `picomatch` (ReDoS với extglob, GHSA-fc5q-39xc-vjpf) đi kèm `eslint-config-next` → `fast-glob` / `tinyglobby`. Advisory áp dụng cho mọi phiên bản (chưa có bản vá). Chỉ chạy lúc lint với pattern do dự án tự viết, không có trong bản deploy (standalone không chứa dev dependency). Chấp nhận, kiểm tra lại khi nâng cấp.

## Content layer & API (GĐ3)

| Chủ đề                    | Quyết định                                                                                                                      | Lý do                                                                                                                    |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Cache fetch               | `cache: 'force-cache'` + `next: { revalidate: 3600, tags }`; tìm kiếm (`revalidate: 0`) → `cache: 'no-store'`                   | Next 16: cache `fetch` là opt-in (tài liệu `node_modules/next/dist/docs/.../fetch.md`).                                  |
| Timeout 8s                | `AbortSignal.timeout` **và** bộ hẹn giờ riêng (`Promise.race`)                                                                  | `patch-fetch.js` của Next bỏ `signal` khi revalidate nền bản cache đã cũ — chỉ dùng signal thì request nền có thể treo.  |
| Gộp request trùng         | Hàm gọi API bọc React `cache()`                                                                                                 | Truyền `signal` làm Next tắt memoization của fetch; `cache()` chỉ sống trong một lần render (không phải state toàn cục). |
| Lỗi API                   | Luôn throw lớp lỗi riêng (`lib/api/errors.ts`); 404 → `ApiNotFoundError`                                                        | Không trả dữ liệu rỗng → Next giữ bản cache tốt gần nhất; trang tự quyết định `notFound()`.                              |
| Response API trang        | Section có mặt phải đủ và đúng schema; mọi section trong response đều được validate kể cả section đang dùng static              | Không render nửa vời; phát hiện sớm backend trả sai.                                                                     |
| Schema trang              | Section theo **key** (không theo mảng có `type`)                                                                                | Cấu hình nguồn theo section (`sections: { hero: 'api' }`), typecheck bắt key sai.                                        |
| Nội dung tĩnh             | `satisfies PageInput<slug>` (typecheck) + validate zod trong `prebuild` (`npm run test:content`)                                | Sai kiểu → typecheck báo; sai ràng buộc (độ dài, link, số phần tử) → build dừng kèm đường dẫn field.                     |
| Giới hạn import           | ESLint `no-restricted-imports`: `app/**` không đọc `content/pages/*`, adapter; `components/**` chỉ `import type` từ content/api | Bảo đảm component chỉ nhận props, trang chỉ đi qua content layer.                                                        |
| Mock backend              | `mocks/server.mjs` Node thuần (0 dependency), đọc JSON từ đĩa mỗi request, giả lập lỗi qua `MOCK_FAIL` hoặc `POST /__mock/fail` | Chạy thật như backend để thử ISR/revalidate; chạy được cả trên hosting (GĐ4).                                            |
| Biến `BACKEND_TIMEOUT_MS` | Tên riêng, không dùng `API_TIMEOUT_MS`                                                                                          | Máy dev đã có sẵn biến `API_TIMEOUT_MS` (của công cụ khác) — trùng tên làm env sai.                                      |
