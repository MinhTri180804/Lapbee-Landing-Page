Renders a Lucide outline icon (1.5–2px stroke) tinted with currentColor — use for every glyph in LAPBEE UI.
```jsx
<Icon name="laptop" size={24} />
<Icon name="arrow-up-right" size={16} color="var(--fg-2)" />
```
- Names are Lucide kebab-case (lucide.dev). Loaded from lucide-static CDN via CSS mask.
